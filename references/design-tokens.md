# 小胰宝社区品牌设计令牌与版式（xyb-md2pdf）

改样式时**只改 `scripts/md2html.py` 里的 `BRAND` 字典与 `css()` 函数**，不要在别处硬编码颜色。本文件是那份代码的说明与对照表。

## 一、色板（小胰宝 v2.0 令牌）

| 令牌名 | 色值 | 用途 |
|---|---|---|
| `mint` | `#299D8C` | 主色：表格表头、h2 左竖条、列表圆点、状态标签实底、页眉页脚分隔线 |
| `mint_deep` | `#1F7A6E` | 深一档薄荷：h3 标题、链接、强调文字 |
| `ink` | `#213139` | 深墨：文档标题、正文加粗、深色标签 |
| `body` | `#48565A` | 正文文字 |
| `light` | `#EDF6F3` | 浅底块面：引用提示块、封面渐变起点 |
| `light_soft` | `#F5FAF9` | 更浅底：表格隔行、代码底 |
| `line` | `#D8E6E2` | 分隔线、边框 |
| `muted` | `#7C8B8F` | 弱化灰：页眉页脚、元信息标签、尾注 |

> 与 `xyb-ppt-template` 的关系：本技能用的是该技能**链路 B（python-pptx / v2.0）**的 5 色令牌。链路 A（slidep）的 `#123F3B / #168B80 / #08665F` 是另一套，**不要混用**。

## 二、字体

```
"Helvetica Neue","PingFang SC","Hiragino Sans GB","Noto Sans CJK SC","Source Han Sans SC",sans-serif
```

latin 走 Helvetica Neue，中文走苹方；等宽用 `"SF Mono",Menlo,Consolas,monospace`（仅代码）。

字号阶梯：文档标题 17.5pt ｜ h2 12.5pt ｜ h3 10pt ｜ 正文 9.5pt、行高 1.8 ｜ 表格 8pt（6 列 7.6pt / ≥7 列 7pt）｜ 页眉 8px ｜ 页脚 7.5px。段落后距 3mm，列表项后距 2.5mm。

## 三、版式

纸张 A4；PDF 默认边距上 16mm / 下 18mm / 左右 18mm（页眉页脚占上下边距区）。HTML 屏幕最大宽度 1020px，桌面左右留白 48px，窄屏 18px；窄屏表格横向滚动。

**封面（hero）**：浅薄荷渐变底 + 1px 边框 + 圆角 4mm；左侧 logo 22mm（透明底 PNG 直接放，JPG 自动加圆角白底框）；中部「小胰宝社区 · 维护出品」+ 英文副行；右侧薄荷实底标签（如「监测日报」）；下方标题、副标题、元信息标签组（白底 + 边框 + 圆角 2mm）。

**页眉（每页）**：高 11mm，底部 0.4mm 薄荷分隔线；左：logo 7mm + 「小胰宝社区」（薄荷绿粗体）+ 文档名；右：副标题或日期（弱化灰）。

**页脚（每页）**：高 10mm，顶部 0.4mm 薄荷分隔线；左：「小胰宝社区维护 ｜ © 年份 小胰宝社区 · 版权归小胰宝社区所有 ｜ 不构成医疗或投资建议」；右：「第 X / Y 页」。

## 四、Markdown → 样式对照

| Markdown | 渲染 |
|---|---|
| 第一个 `# 标题` | 封面主标题（并从正文中移除，不重复出现） |
| 头部 `**键**：值` 行 | 封面元信息标签；正文中不再重复 |
| `## N. 小节` | h2，左侧 1.6mm 薄荷竖条，6mm 上间距，`break-after: avoid` |
| `### A. 小节` | h3，深薄荷色 |
| `**加粗**` | 深墨色加粗 |
| `**已核实**` 等独立成词的加粗 | 状态标签：已核实/已确认 → 实底薄荷；待核实/未核实/未披露/未执行/未支持/未访问 → 白底薄荷描边；首次基线/基线 → 深墨实底；外部 → 灰底 |
| 整格只有状态词的表格单元格（如 `\| 待核实（付费墙） \|`） | 同上；关键词成标签、括注保留为普通文字（监测日报「证据状态」列多为此形态，没加粗也认得出） |
| `- 列表` | 薄荷圆点；嵌套层用浅薄荷小点 |
| `1. 列表` | 数字序号，序号着色为深薄荷 |
| `\| 表格 \|` | 品牌绿表头白字 + 隔行浅底 + 首列最小宽度 14mm，再由内容自适应；≥6 列自动缩字号 |
| 裸 `https://...` | 自动成链，`word-break: break-all` 防溢出 |
| `> 引用` | 浅薄荷底圆角提示块 |
| `---` | 浅色细分隔线 |
| ``` 代码块 ``` | 浅底 + 边框 + 等宽字体，自动换行 |
| 文末 | 薄荷上边框 + IP 归属声明 + 原始文档名 + 生成时间 |

## 五、CSS 打印要点（改版式时别踩）

- 标题避免落在页底；段落设置 `orphans` / `widows` 并尽量整段分页；表格重复表头，表格行不拆分。避免对可能超过整页的容器强制 `break-inside: avoid`。
- Markdown 原文可单独插入 `<div class="page-break"></div>` 让后续内容从新页开始。分段只依据原文空行，不改写正文。

- `break-inside: avoid` 用在封面、提示块、表格行、尾注上；`break-after: avoid` 用在所有标题上，避免标题孤行落页尾。
- 页眉页脚由 Chrome 打印模板渲染，**不共享页面 CSS**，必须内联样式；logo 以 data URI 内嵌。
- 表格一律 `border-collapse: collapse`，长 URL 用 `word-break: break-all`。
- 封面渐变用 `linear-gradient(135deg, …)`，靠 `print_background=True` 才会打印出来。
